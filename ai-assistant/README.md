# AI 助手

在服务器页面提供 AI 对话，用来定位控制台报错、给出修复命令与配置文件。

插件不会自动执行任何操作。模型只输出「待确认提案」，用户在面板里点确认之后才会生效。

## 功能

- 读取最近 100 行控制台日志（Wings 上限），只读
- 列目录、按行读文本文件、按内容搜索；密钥、凭据、数据库文件始终排除
- 附件：可勾选文件（读内容）与文件夹（只列文件名），根目录可单独勾选，支持全选与反选
- 生成命令与文件时转为待确认卡片，确认后由后端二次校验再执行
- 可选按 Token 扣积分，走「经济系统」的 `Wallet` 契约
- 可选联网搜索，搜索结果计入工具预算
- 用户可自带 API Key，用自己的额度，不扣平台积分
- 开启计费后，每条回复下方显示本次消耗的积分

不提供的能力：删除文件、修改启动命令、修改服务器设置、跨服务器访问、任意 shell、上传下载。

## 安装

从 [releases](https://github.com/pterodactyl-china/extensions/releases/latest) 下载 `ai-assistant.zip`，在面板主机上执行：

```sh
php artisan p:extension:install /path/to/ai-assistant.zip --enable
php artisan optimize:clear
```

装完进「管理 > AI 助手」填 API Key，按需开启命令执行与文件生成，再配置白名单和可读目录。

## 后台设置

| 设置项 | 默认 | 说明 |
| --- | --- | --- |
| AI 提供商 | DeepSeek | OpenAI、Anthropic、Gemini、OpenRouter、Ollama 等，选择后自动填默认地址 |
| API Key | 空 | 加密存储，只存数据库，不下发前端 |
| 接口地址 / 模型 | 空 | 部分服务商可留空；自定义与 CodeBuddy 必填模型 |
| 开放范围 | 所有预设 | 或「仅指定标签」，标签从「管理 > 标签」读取 |
| 允许执行命令 | 关 | 关闭时只能查看，不能下发 |
| 命令放行模式 | 全部 | 全部允许，或仅白名单 |
| 命令白名单 | 空 | 仅「仅白名单」模式生效 |
| 允许生成文件 | 关 | 关闭时不能写入 |
| 可读目录 | `*` | `*` 为整个服务器，`.` 为根目录 |
| 每人每天提问次数 | 0 | 0 表示不限 |
| 每人每天 Token 上限 | 0 | 0 表示不限 |
| 每分钟提问次数 | 10 | 0 表示不限 |
| 单次回复最大 Token | 0 | 0 表示不限，交给模型自身的上限 |
| 未计费时的单次上限 | 400 | 0 表示不限 |
| 请求超时 | 60 秒 | 5–120 |
| 按 Token 扣积分 | 关 | 依赖经济系统 |
| 多少 Token 扣 1 积分 | 1000 | 向上取整，最低 1 分 |
| 搜索服务 | 关闭 | DeepSeek、Tavily、Serper、自定义接口 |
| 每次搜索扣积分 | 0 | 用平台 Key 时按次扣，用户自带搜索 Key 不扣 |
| 系统提示词 | 空 | 安全规则固定追加，无法被覆盖 |

配置存在 `extension_settings` 表，管理入口只有「管理 > AI 助手」，不在「管理 > 扩展」里重复出现。

## 命令白名单

```
prefix:stop                    # 前缀匹配
/^whitelist (add|remove) /     # 正则匹配
save-all                       # 完全匹配
```

无论哪种模式，带换行、`;`、`|`、`&`、反引号、`$`、`<`、`>` 或超过 200 字符的命令都会拒绝。

## 权限

命令需要 `control.console`，读文件需要 `file.read` 与 `file.read-content`，写文件需要
`file.create` / `file.update`。另外还要后台对应的开关处于开启状态。

文件读写不限目录，但会拦截绝对路径、`..` 和敏感文件（`.env`、`*.key`、`*.pem`、`*.sqlite`、
`id_rsa*`、`auth.json` 等）。提案绑定用户与服务器，10 分钟过期，执行后立刻失效。

## 工具

| 工具 | 作用 | 上限 |
| --- | --- | --- |
| `list_dir` | 列目录，只给名称与大小 | 200 项 |
| `read_file` | 按行分段读文本 | 单次 200 行，文件不超过 256 KB |
| `grep` | 目录内搜索，返回 `文件:行号:内容` | 40 条 |
| `web_search` | 联网搜索 | 5 条结果 |

单轮最多 3 次工具调用，单次对话共享 24 KB 预算，超出后返回「预算用尽」。

后台可以按名字禁用内置工具，也可以加自定义工具：

```
管理 > AI 助手 > 工具集
  禁用的内置工具   web_search,grep
  自定义工具        ip_lookup|查询 IP 归属地|https://api.example.com/ip?q={query}
```

自定义工具只支持 GET、必须是 https 且解析到公网地址，返回内容截断到 8 KB 并计入统一预算。

## 联网搜索

支持 DeepSeek 官方搜索、Tavily、Serper 和自定义接口。自定义接口的地址用 `{query}` 占位，
鉴权走 `Authorization: Bearer <key>`，响应兼容 `results`、`data`、`organic` 三种结构。

没配搜索服务时，OpenRouter 的模型可以加 `:online` 走它自己的联网，由「未配置时用模型自带联网」
这个开关控制，默认关闭。

搜索接口按次计费。用平台 Key 时按「每次搜索扣积分」扣，用户自己填了搜索 Key 就不扣。

## 计费

开关叫「按 Token 扣积分」，默认关闭。关闭时不读余额、不扣费。

```
本次积分 = ceil(total_tokens / tokens_per_credit)
```

付费用户与自带 Key 的用户默认不限制输出长度，请求里不传 `max_tokens`，由模型自己决定；
要控成本就在后台把「单次回复最大 Token」填成具体数字。免费额度那一档仍然保留上限，
因为它本来就是防滥用的。

发请求前会按「输入字符 ÷ 4 + 单次上限」估一个下限，预估都不够就直接返回 402，避免发了请求却扣不动。
实际用量超过预估是正常的，超出部分由账本记成负数，下次充值自动抵扣；余额已经是负数时，要先还款才能继续。

没装经济系统时降级为不扣费，页面也不显示余额。

## 用户自带 Key

服务器页右侧「使用我的 API」里可以填自己的 Key，按用户加密存储，管理员看不到，
跨服务器共用。填了之后对话走用户自己的额度，不扣积分，也不受余额限制。

用自带 Key 时，命令白名单、文件权限和提示注入防护照样生效。

## 常见问题

| 现象 | 原因 |
| --- | --- |
| 401 | Key 不对，或者用的是海外站签发的 `ck_` Key 访问了中国版 |
| 404 | 接口地址多写/少写了 `/v1`，或服务商不提供 `/models` |
| 422 | 模型名不存在，或服务商要求的字段不同 |
| 超时 / 502 | 网络不通，或超过设定的超时 |

测试连接失败会显示上游返回的原文，照着调模型名或地址即可。CodeBuddy 的 `ck_` Key
只能用 `www.codebuddy.cn`，接口强制流式，插件会把 SSE 读完整再拼成一次回复。

## 说明

- 会话存在浏览器 `localStorage`，按服务器隔离，保留最近 60 条
- 跳过空白字符，`Enter` 发送，`Shift + Enter` 换行
- 待确认提案有 10 分钟有效期，刷新页面不会恢复
- 用户消息、日志、文件内容都按数据处理，不参与指令解析
