# 备案信息

在国内大陆地区部署面板时，页面上需要展示 ICP 备案号、公安备案号与 ICP 许可证。
本扩展把这三项放到面板的固定位置，点击即可跳转对应的官方查询系统。

- **ICP 备案号** → [工业和信息化部政务服务平台](https://beian.miit.gov.cn/)
- **公安备案号** → [全国互联网安全管理服务平台](https://beian.mps.gov.cn/)，查询参数取自备案号中的数字
- **ICP 许可证号** → [电信业务市场综合管理信息系统](https://tsm.miit.gov.cn/dxxzsp/)

## 安装

从最新版本中下载 [beian.zip](https://github.com/pterodactyl-china/extensions/releases/latest/download/beian.zip)，
然后在面板所在主机上执行：

```sh
php artisan p:extension:install /path/to/beian.zip --enable
```

重新加载面板，随后可在「管理 > 扩展 > 备案信息」中填写号码。

## 设置项

| 设置项 | 示例 | 说明 |
| --- | --- | --- |
| ICP 备案号 | `京ICP备2023012345号-1` | 留空则不显示 |
| 显示 ICP 备案号 | 开启 | 关闭后该项隐藏，号码保留 |
| 公安备案号 | `京公网安备 11010502030146号` | 留空则不显示；链接中的 `code` 取自号码里的数字 |
| 显示公安备案号 | 开启 | 关闭后该项隐藏，号码保留 |
| ICP 许可证号 | `京B2-20230123` | 增值电信业务经营许可证，留空则不显示 |
| 显示 ICP 许可证号 | 开启 | 关闭后该项隐藏，号码保留 |

三项互相独立：填了哪项就显示哪项，填一项显示一项、填两项显示两项；每项都有开关，关闭即从页面上消失。
三项都留空或都关闭时，页面底部不显示任何内容。填写后无需重新构建，刷新页面即可生效。

## 显示位置

与 1.0 面板的页脚一致：固定在页面最底部、居中，一行显示所有已填写的号码；未登录的登录页同样显示。

面板 2.0 的前端没有页脚插槽，因此扩展把自己的页脚元素挂到 `body` 上，不随路由切换重建，
并给 `body` 补了等高的下内边距，避免遮住页面最底部的内容。

号码是纯文本，会随面板的浅色/深色主题自动变色。

## 说明

- 三个号码都是 `->frontend()->public()` 设置，未登录的页面也会读取；因此不要在这里放任何私密内容。
- 公安备案号前会显示官方徽标。图片取自公安部备案系统的 `https://beian.mps.gov.cn/img/logo01.dd7ff50e.png`，
  已随扩展打包在 `src/client/assets/police-badge.png`，运行时不会请求外部地址；官方更新图标时替换该文件并重新构建即可。
- 本扩展不创建数据表、不注册路由，停用后不会留下任何残留数据。
