# 计划任务时间

把计划任务弹窗里那五个 cron 输入框，换成更好用的可视化设置。默认开启，点一下就能切回手动填写。

## 用法

服务器 → 计划任务 → 新建任务 / 编辑任务，弹窗里会出现「执行时间」面板：

```
执行时间                                        [手动填写]
选择频率后会自动填写下方的 cron 字段。

频率 [每天 ▾]          小时 [03]  分钟 [00]

每天 03:00 执行                              0 3 * * *
```

| 频率 | 说明 | cron |
| --- | --- | --- |
| 按间隔 | 每 N 分钟（1–59） | `*/N * * * *` |
| 每小时 | 每小时的第 M 分 | `M * * * *` |
| 每天 | 每天 HH:MM | `M H * * *` |
| 每周 | 周几多选 + HH:MM | `M H * * D` |
| 每月 | 每月 D 日 HH:MM | `M H D * *` |

打开弹窗时如果已有 cron，会自动识别成上面某种模式；识别不了的组合**不会立刻被覆盖**，面板会保留原表达式，只有你真正改了一次频率才写回。

## 保留手写 cron

点「手动填写」，原始五个输入框重新出现，可视化面板收起。再次点击即可切回。这就是「自定义」的唯一入口，所以频率下拉里没有这一项。

## 说明

- 没有后台设置项，也没有数据表；纯前端注入
- 面板本身没有给这个弹窗留 slot，所以用 DOM 注入实现：检测 `[role="dialog"]` 里的五个 cron 字段，找到后在其上方插入面板
- 写回值用原生 `value` setter + `input` 事件，React 受控表单能正常收到
- 面板文案跟随主题语言；若主题把 label 翻译了，会退回「第一个文本框是名称，后五个是 cron」的按位置识别

## 安装

```sh
php artisan p:extension:install /path/to/cron-builder.zip --enable
php artisan optimize:clear
```

装好后直接打开计划任务弹窗即可，无需额外配置。
