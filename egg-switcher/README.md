# 预设切换（egg-switcher）

在服务器「启动」页切换预设（egg），类似 1.0 的预设选择，但按 2.0 的「标签 + 预设」模型做权限与范围控制。

## 能力

| 项 | 说明 |
| --- | --- |
| 位置 | 服务器「启动」页，**启动命令与 Docker 镜像之后、变量之前** |
| 查看当前预设 | 卡片右上角显示预设名 |
| 标签切换 | 顶部标签按钮是**单选**：点一下切到该标签，再点一下取消（全部）；后台可关闭跨标签 |
| 可选列表 | 只列允许标签内的预设 |
| 切换 | 调用面板自带的 `ChangeServerEgg`：更新 `egg_id`、启动命令、镜像，并按需重建变量 |
| 同步 | 切换后调用 `Daemon::sync()`，Wings 立刻拿到新配置 |
| 生效 | 需要重启服务器；卡片里明确提示 |

服务器上的文件（存档、插件、配置）不受影响，只换「怎么启动」。

## 子用户权限

插件向面板注册了两个权限，出现在「服务器 → 用户 → 编辑权限」的「预设切换」分组里：

| 权限值 | 作用 |
| --- | --- |
| `ext.egg-switcher.view` | 查看当前预设与可切换列表 |
| `ext.egg-switcher.switch` | 执行切换（会改动启动命令、镜像与变量） |

- 服务器所有者与 root 管理员自动拥有全部权限（面板策略决定）
- 只给 `view` 的用户能看到卡片但不能切换，卡片里会说明缺少哪个权限
- 两个权限都没有时，卡片不渲染，接口直接 403

## 后台设置

「管理 → 预设切换」是唯一配置入口（不再注册面板的扩展设置表单，避免重复）：

| 设置项 | 默认 | 说明 |
| --- | --- | --- |
| 切换时保留同名变量 | 开 | 新预设里同名环境变量沿用旧值 |
| 允许用户在服务器页按标签筛选预设 | 开 | 关闭后服务器页只显示预设下拉，不显示标签按钮 |
| 允许的目标预设标签 | 空 | **直接从面板「管理 → 标签」读取，勾选即可**；不选表示所有预设都可切换 |

### 跨标签开关（核心）

后台「允许切换标签」决定用户在服务器页能选到什么：

| 开关 | 服务器页表现 | 后端校验 |
| --- | --- | --- |
| **关闭**（默认） | 只显示**当前预设的标签**（只读），下拉里只有同标签预设 | 必须与当前预设共享标签 |
| **开启** | 显示面板**全部标签**，可先点标签筛选、再选该标签下的预设 | 只校验管理员白名单 |

```
关闭：Forge Minecraft（minecraft）
      → 只能看到 minecraft 标签
      → 下拉只含带 minecraft 的预设

开启：Forge Minecraft（minecraft）
      → 显示 minecraft / paper / rust / source-engine … 全部标签
      → 点 rust 就能选 Rust 预设
```

管理员白名单（「允许的目标预设标签」）在两种模式下都生效，作为最终上限。

当前预设没有标签时，关闭模式下没有可比较的基准，所以只按管理员白名单限制。

前端只渲染可用的预设，后端 `POST /switch` 会重新校验，绕过界面直接调接口也会被拒。

### 关于「预设组」

2.0 已用**标签**取代了 Nest：`Egg` 模型里只有 `tags()` 关联，`nest_id` 只是迁移遗留列。
所以本插件不提供「同预设组」这类限制，可切换范围完全由标签决定。术语上：

| 面板实体 | 本插件显示 |
| --- | --- |
| Egg | 预设（与面板中文说明一致） |
| Tag | 标签 |

## 接口

都挂在 `/api/client/servers/{server}/extensions/egg-switcher`：

```
GET  /        当前预设 + 可选列表（含 allowed / reason）
POST /switch  { "egg_id": 12 }
```

## 安装

```sh
php artisan p:extension:install /path/to/egg-switcher.zip --enable
php artisan optimize:clear
```

装好后：

1. 到「管理 → 预设切换」勾选允许切换的标签
2. 到服务器「用户」里给需要的子用户勾选权限
3. 服务器「启动」页会出现「服务器预设」卡片

## 注意

- 切换会**删除旧预设的变量记录**，只保留新预设里同名的项（与面板后台改预设的行为一致）
- 若新预设的启动命令引用了不存在的文件，服务器可能起不来，建议切换后先看一次控制台
- 跨 Nest 切换只在关闭「同一 Nest」限制后可用，且仍需满足标签规则
