# 预设切换（egg-switcher）

在服务器「启动」页切换预设（egg）。按 2.0 的标签模型限定可选范围，并按子用户权限控制操作。

## 功能

| 项 | 说明 |
| --- | --- |
| 位置 | 服务器「启动」页，位于启动命令与 Docker 镜像之后、变量之前 |
| 当前预设 | 卡片标题栏右侧显示预设名 |
| 标签切换 | 顶部标签为单选，点击切换，再次点击取消；是否允许切换由后台控制 |
| 可选列表 | 仅列出允许范围内的预设 |
| 切换 | 调用面板的 `ChangeServerEgg`，更新 `egg_id`、启动命令、镜像，并按需重建变量 |
| 同步 | 切换后调用 `Daemon::sync()`，Wings 立即获取新配置 |
| 生效 | 需要重启服务器，卡片内会提示 |

服务器上的存档、插件与配置文件不受影响，仅更换启动方式。

## 子用户权限

插件注册两个权限，显示在「服务器 → 用户 → 编辑权限」的「预设切换」分组。

| 权限值 | 作用 |
| --- | --- |
| `ext.egg-switcher.view` | 查看当前预设与可选列表 |
| `ext.egg-switcher.switch` | 执行切换 |

- 服务器所有者与 root 管理员由面板策略自动获得全部权限
- 仅有 `view` 权限时可以看到卡片，但无法切换
- 两个权限都没有时卡片不渲染，接口返回 403

## 后台设置

配置入口只有「管理 → 预设切换」，插件不注册面板的扩展设置表单。

| 设置项 | 默认 | 说明 |
| --- | --- | --- |
| 切换时保留同名变量 | 开 | 新预设中同名的环境变量沿用原值 |
| 允许切换标签 | 关 | 开启后可按标签切换到其他预设；关闭时只能在当前预设的标签内选择 |
| 允许的目标预设标签 | 空 | 读取面板「管理 → 标签」，勾选保存；不选表示不额外限制 |

### 标签规则

| 开关状态 | 服务器页表现 | 后端校验 |
| --- | --- | --- |
| 关闭 | 只显示当前预设的标签（只读），下拉仅包含同标签预设 | 目标预设必须与当前预设共享标签 |
| 开启 | 显示面板全部标签，可切换标签后选择对应预设 | 只校验允许的目标预设标签 |

示例：当前预设为 Forge Minecraft，标签为 `minecraft`。

```
关闭时：标签只有 minecraft，下拉只含带 minecraft 的预设
开启时：标签显示 minecraft、paper、rust 等，切到 rust 后可选 Rust 预设
```

「允许的目标预设标签」在两种状态下都生效，作为最终限制。当前预设没有标签时，关闭状态下没有可比对的基准，仅按该白名单限制。

前端只渲染可用预设，后端在 `POST /switch` 中重新校验，直接调用接口同样会被拒绝。

### 术语

面板 2.0 使用标签取代了 Nest，`Egg` 模型只保留 `tags()` 关联，`nest_id` 为迁移遗留字段。

| 面板实体 | 本文档用词 |
| --- | --- |
| Egg | 预设 |
| Tag | 标签 |

## 接口

均位于 `/api/client/servers/{server}/extensions/egg-switcher`。

```
GET  /        当前预设与可选列表
POST /switch  { "egg_id": 12 }
```

## 安装

```sh
php artisan p:extension:install /path/to/egg-switcher.zip --enable
php artisan optimize:clear
```

安装后：

1. 在「管理 → 预设切换」中设置是否允许切换标签，并勾选允许的目标预设标签
2. 在服务器「用户」中为子用户授予权限
3. 服务器「启动」页会出现「预设」卡片

## 注意事项

- 切换会删除旧预设的变量记录，仅保留新预设中同名的项，与面板后台修改预设的行为一致
- 新预设的启动命令若引用不存在的文件，服务器可能无法启动，建议切换后查看一次控制台
- 跨标签切换需要开启「允许切换标签」，且目标预设仍需满足标签限制
